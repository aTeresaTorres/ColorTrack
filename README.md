# ColorTrack v2.0

## 🎬 Tráiler

[![ColorTrack Trailer](https://img.youtube.com/vi/oA0m4LtAl3A/maxresdefault.jpg)](https://youtu.be/oA0m4LtAl3A)

Haz clic en la imagen para ver el tráiler oficial.

## 1. Descargar el juego

1. Ve a la sección **Releases** (en la parte derecha de este repositorio).
2. Descarga el archivo **ColorTrack_v2.0.zip**.
3. Extrae el contenido en una carpeta.

## 2. Ejecutar

1. Abre la carpeta extraída.
2. Haz doble clic en **ColorTrack.exe**.
3. ¡Disfruta!

> ⚠️ **IMPORTANTE:** El archivo `ColorTrack.pck` debe estar en la misma carpeta que `ColorTrack.exe`. No lo muevas ni lo borres.

---

## 🎯 Requisitos

- Windows 10 o superior
- 512 MB de RAM
- Resolución mínima: 1152×720

---

## 📝 Nota para desarrolladores

Si quieres ver o modificar el código fuente:

1. Clona este repositorio.
2. Abre el proyecto con **Godot 4.6.1** o superior.
3. Ejecuta el proyecto desde el editor.

---

## ❓ ¿Problemas?

Si el juego no abre o se cierra:

- Asegúrate de que `ColorTrack.exe` y `ColorTrack.pck` estén en la misma carpeta.
- Si el problema persiste, abre el **Símbolo del sistema (CMD)** y ejecuta:

```cmd
cd "ruta\de\tu\carpeta"
ColorTrack.exe
```

De esta forma podrás ver mensajes de error más detallados para diagnosticar el problema.
